Using a literature-review skill

This skill was written for this workshop. Download it, read the instructions, and put the folder in the project where you want to work.

Download literature-audit.zip · Open SKILL.md

1. Put the skill in the project

Codex CLI / IDE:  .agents/skills/literature-audit/SKILL.md
Claude Code:      .claude/skills/literature-audit/SKILL.md

These paths are relative to your research project. Restart the session if the new skill does not appear.

2. Invoke it and give it an assignment

Codex CLI / IDE:  $literature-audit
Claude Code:      /literature-audit

The file can also be attached directly with an explicit instruction to follow it. The host still needs search and file tools; a skill supplies instructions, not subscription access.

Assess whether AI chatbots reduce requests for emotional support or personal advice to existing friends and family. Find 8–12 primary studies. Record queries and inclusion decisions. Check the actual instruments and source versions. Produce an evidence table and verified bibliography. Ask me about consequential ambiguities before drawing a conclusion.

Use separate source and methods reviewers. Have them cross-check each other's objections. Preserve disagreements and questions for me.

3. Open what it produced

Evidence table · Search record · Actual reviewer reports · Compiled proposal

The original review predates this reusable skill. The reviewers were run during this revision. These files are not presented as the result of a recorded Claude Code session: the local Claude login had expired, and the installed Codex CLI executable was unavailable. The paired dialogue is scripted.
